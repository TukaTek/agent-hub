# CortexAI brand assets

`cortexai-icon.png` and `cortexai-logo.png` are the official CortexAI assets published at
[tukasolutions.com](https://www.tukasolutions.com/). Do not redraw or recolor the source files.

Run `pnpm brand:generate` after changing either source asset. The generator produces the web,
desktop, mobile, social-card, and README derivatives from this single source of truth.
